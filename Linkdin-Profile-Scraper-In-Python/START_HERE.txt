📋 WHAT HAPPENS:

✅ Browser opens and logs into LinkedIn
✅ If CAPTCHA appears → solve it in the browser window
✅ Script automatically detects when you're done
✅ Scrapes all profiles (name, headline, about, experience, education)
✅ Saves individual JSON files: {Name}_profile_data.json
✅ Saves combined file: all_profiles.json


🛡️ CAPTCHA HANDLING:

When CAPTCHA appears:
1. Script prints: "⚠️ CAPTCHA DETECTED!"
2. You solve it in the browser (click checkbox, solve images)
3. Script waits and shows countdown
4. Automatically continues when solved

You have 120 seconds to solve it!
